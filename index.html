このサイトの使い方

「いま募集中 × 予算が合う × VTuber を描ける」絵師を探す社内ツールです。

🖼 絵だけ表示 / 📋 カード表示

既定は🖼 絵だけ＝絵師1人につき代表作1枚と「名前・価格」だけ（押すと🔍詳細ビュー、PC はマウスを載せると2枚目。R-18 の作品しか無い絵師はぼかし、⭐は誰かが⭐した絵師）。 ⭐・🚫除外は🔍詳細ビューでもできます。バッジや条件を並べて見るときは📋 カードで。切り替えは PC は上部バー、スマホは下のタブ（カードへ／絵だけへ）か⚙内で、選んだ表示は端末に保存されます。

並び順（既定は新着順）

新着順＝このツールが絵師を初めて見つけた日の新しい順（Skeb に登録した日ではありません）。同じ日に見つけた絵師どうしは、下の「おすすめ順」の基準で並びます。

🆕 前回開いたあとに新しく見つけた絵師には NEW の目印（絵だけの表示は絵の右下）が付き、件数の左に「🆕 前回から +N 名」が出ます（いまの条件の中の人数。押すとその絵師だけ・もう一度押すと解除）。 「前回」はこの端末で前に開いたときのデータ（そのときいちばん新しかった見つけた日）で、同じ日のデータのうちは読み込み直しても目印は消えません。 この端末で初めて開いたときは、データの新しい方から2日に見つけた絵師に付きます。見つけた日で決めるので、前から台帳にいて後から一覧に載った絵師には付きません。イラスト版とコミック版は別々に覚えます。

並び順「おすすめ順」の基準

「今すぐ頼める × VTuber を描ける」絵師を上に出します。

1主対象（◎）を最優先 ＝「募集中」かつ「イラスト」かつ「VTuber適性が 確実 / 有力」の絵師（カードが金枠）。
2次に受付状況：募集中 → 受付不明 → 休止中。
3同じならVTuber適性スコアの高い順。

ほかに 価格 / 納期 / VTuber適性 / 完了率 / 受注数 / Skeb人気順 / 売上規模 / 名前 で並び替えできます。

VTuber適性ランクの意味

  • 確実 名鑑の VTuber 名などの手がかりが 3 点以上（個人名 1 人＝1.5 点・事務所/ユニット名＝0.5 点・「VTuber」「Live2D」「立ち絵」等の語＝0.5 点〔3 語まで〕）。プロフィール文・依頼文のほかSkeb検索のタグも見ます。名鑑にヒットした名前は 🔍詳細ビューのチップで確認できます
  • 有力 同じ手がかりが 1 点以上 3 点未満（例: 個人名 1 人、または「VTuber」「Live2D」等の語 2 つ）
  • 候補 弱い手がかりのみ

※その絵師が描いた可能性の高い VTuber 名は 🔍詳細ビューで確認できます（検索枠に VTuber 名を入れて探すことも可能）。

絞り込み

  • 募集中のみ：いまリクエスト受付中だけ表示（既定）。🔁 募集再開（30日以内）＝休止中だった絵師が募集中に戻ったのを直近30日に確かめた絵師だけ （カードに「🔁 再開」、絵だけの表示は絵の右下に「再開」〔NEW の絵師は NEW〕）。休止中の絵師は主に毎週日曜の全件確認で確かめるので、日付は「確かめた日」で、実際の再開はたいていその前の1〜2週間のどこかです（受付中の絵師の検索で先に見つかることもあります）。人気の絵師は枠がすぐ埋まるので早めに
  • 価格：スライダーで下限〜上限の予算範囲を指定（絵師のイラスト最低額が範囲内なら表示。範囲指定中は価格不明の絵師は出ません）
  • 納期：クリエイター設定の納品期限（リクエスト承認から◯日以内に納品）で絞る。平均実績ではなく本人設定の上限です。データは順次取得中のため、未取得の絵師は絞り込み中は表示されません
  • 見つけた日：このツールが絵師を初めて見つけた日で絞る（データでいちばん新しい見つけた日から数えて 3日／1週間／1か月。Skeb に登録した日ではありません）。新着順と組み合わせると「今週入った絵師」をまとめて見られます
  • VTuber適性：「確実のみ / 有力以上 / 候補以上」で絞る
  • 実績：Skeb に公開されている受注数と完了率（収集した時点）で絞る。選択肢の文がそのまま基準です （「受注20件以上・完了率95%以上」＝両方を満たす絵師。ほかに 10件・90% と 50件・98%）。隠れた点数や重み付けはありません。 完了率が出ていない絵師（受注0件）は絞り込み中は表示されません。並び替えの「完了率」「受注数」と同じデータです
  • 🎨 絵柄：デフォルメ・男性キャラ・ケモノ・厚塗り・和風などの絵柄・描くもので絞る（複数選ぶとすべて満たす絵師だけ。チップの数字はそれを足したら残る人数）。 プロフィール文・Skeb検索のタグ・過去の依頼文から機械的に推定したもので、「ケモノNG」のような断り書きはできる範囲で除いています。 タグ由来は「その題材の作品が1つ以上ある」程度の意味で、得意・専門とは限りません。 塗り・タッチ（デフォルメ・厚塗り・アニメ塗り・水彩・ドット絵・アナログ・モノクロ）と、描く対象のうち「ケモノ・獣人」「人外・クリーチャー」「メカ・ロボ」「背景・風景」は作品の絵からも推定しています（AI がこの社内の PC でイラストの作品サムネを数値にして判定。画像は保存しません）。 絵の数値がある絵師は、タグだけで当たっていても絵の点数が低ければ付けず（塗り・タッチは下半分のとき、ケモノ・人外・メカ・背景は上位10%に入らないとき）、絵の点数が上位なら文字が無くても付けます（R-18 の作品しか無いなど絵の数値が無い絵師は、Skeb検索のタグの先頭のほうにあるときだけ付けます）。「男性キャラ」「ホラー・ダーク」「ゴスロリ・地雷系」「和風」は AI が絵から見分けられないので、今までどおり文字だけで推定しています。 これらで絞っている間は、絵だけの表示のタイルにその点数が一番高い作品を出します。 カードの紫のチップを押しても絞れます。🔍詳細ビューで「何から推定したか」を確認できます。 該当なし＝描けない、ではありません（R-18 の作品しか無い絵師などは絵から推定できません）
  • 👑 有名度：Skeb 公式の人気ランキング（Skeb が出している人気順の一覧。全ジャンルの上位 400 位までしか無いので、それより下の絵師には順位が付きません。毎日の更新で取り直し）と、 受注数の上位%（募集中の絵師の中で。件数は選択肢に表示）で絞ります。「👑 有名どころ」＝人気 400位以内か受注 上位5%。 並び替えの「Skeb人気順」「売上規模 大きい順（受注数×今の価格の目安）」も同じデータです。カードに金色の「👑 Skeb人気 ◯位」、絵だけの表示では順位のある絵師の絵の左下に「👑順位」が出ます。 これはSkeb での人気で、業界全体の知名度ではありません（有名なキャラクターデザイン担当〔ママ〕の多くは Skeb にいないか休止中です）。受注数だけで並べると安く数をこなす絵師が上に来るので、Skeb 人気順か売上規模とあわせて見てください
  • 🖼 似ている絵柄（🎨 の中の先頭）：自社キャラ（身ノ程しらず・高ノ嶺はな）の公式の立ち絵と、各絵師の作品サムネ（R-18 以外）を画像で比べ、 タッチ・塗り・雰囲気が近い順に各キャラ上位 300 名まで並べます（1つだけ選べます。選ぶと並び替えが「似ている順」になり、タイルの左上とカードに順位が出ます）。 近さは絵柄を測るよう学習したモデル（CSD）の目安で、髪色や構図に引っ張られることもあります。最後はサムネで確かめてください。 R-18 の作品しか取れていない絵師・作品サムネの無い絵師は比べられないので出ません。新しい絵師は毎日の更新で順に加わります。 数値化はこの PC の中だけで行い、作品の画像は保存していません（数値だけ）。 🔍詳細ビューの「🎨 この絵師に絵柄が近い人」から、気に入った絵師を起点に、作品の絵の数値で近い順（上位12名・一覧に載っている絵師の中で。作品の多い絵師ばかりが出ないよう全員の平均を引いてから比べます）にもできます（イラスト版だけ）。 「一覧で見る」でその12名に絞って近い順（起点の絵師自身は出ません・受付などほかの絞り込みは効いたまま・検索語と🆕だけは外します）、名前を押すとその詳細
  • 利用の記載：プロフィール文に書かれた利用の条件を機械的に読み取って絞る。 記載あり＝保証ではなく目安です。発注前に必ず本人の規約と Skeb の規約を確認してください。
    • 緑のチップ＝できる記載（商用OK・配信・サムネOK・グッズOK・お仕事依頼OK＝「お仕事のご依頼はDMへ」「個人・企業問わず」などお仕事の依頼の窓口がある。多くは DM・メール・HP＝Skeb 外で直接相談できる。「受付停止中」「お休み中」と書いてあるものは除く）
    • 水色＝商用は要相談（「商用はDMで」「グッズ化は別途」「Skeb 以外で」など）
    • 赤＝断っている記載（商用NG・配信NG・グッズNG・二次利用NG）
    「無断転載・商用利用・AI学習禁止」のような投稿作品への注意書きや、ファンアートの扱い・素材の規約は依頼の条件ではないので数えていません。 記載がある絵師は少数で、多くは「お仕事依頼OK」です＝記載なし＝できない、ではありません。 チップにマウスを載せると根拠の文が出ます（🔍詳細ビューにも表示）。「NGの記載がある絵師を除く」で赤の絵師だけ外せます
  • 💾 保存した条件：いまの絞り込み（受付・価格・納期・見つけた日・適性・実績・有名度・🎨絵柄・利用の記載・⭐・状態・並び順・チェック・検索語）に名前を付けてこの端末に保存し、選ぶだけで呼び出せます（最大10件・同じ名前は上書き・「消す」で削除。イラスト版とコミック版は別々）。 呼び出すと保存した条件だけになります（🆕だけは解除）。表示の切り替え・R-18サムネ表示・🆕だけは保存しません。今は選べない条件（共有の取得前の「⭐ 〇〇さん」等）は既定に戻して知らせます
  • 状態：選定ステータス（検討中/打診済/発注済/納品済/見送り）で絞る。⭐絞り込みと併用可。特定の状態を選ぶと受付・価格などの他条件は無視されます（発注済の絵師は受付停止しているのが普通のため）
  • 全年齢中心のみ：取得している作品（最大6作・多くの絵師は2作。多くは直近作）のうち R-18 が半数未満の絵師だけを表示 （2作なら0作、4作なら1作、6作なら2作まで）。作品が1作以下のときは比率で決められないので、Skeb の 「R-18 の依頼を受けない」設定で、作品があればそれも全年齢の絵師だけ。R-18 も受ける設定で作品が無い絵師は判定できないため出ません。 ※カードの R-18 バッジは「R-18 の依頼も受ける設定」の意味なので、全年齢中心の絵師に付くこともあります（🔍詳細ビューに作品の内訳）
  • R-18サムネ表示：オフで成人向け作品サムネをぼかす（既定オフ・安全側）。※R-18も受ける絵師も一覧には常に表示されます（SFW作品も描けるため。バッジで判別可）。「全年齢中心のみ」にしても、R-18 の依頼を受ける設定の絵師は作品が全年齢中心なら残ります（6作中2作までは R-18 を含むことがあり、そのサムネはぼかして表示）
  • 要目視も表示：価格・受付・ジャンルが不明な絵師を含めるか
  • ⭐自分 / ⭐全員 / ⭐ 〇〇さん：お気に入りだけに絞る（下記。〇〇さん＝その人が⭐した絵師だけ）。絞ると受付・価格・納期・適性・実績・全年齢中心・利用の記載 等の他条件は無視して全お気に入りを表示（検索語と🎨絵柄だけは効いたまま。🎨で絞り込み中は件数の横に紫の「🎨 … ✕」が出るので、押せば解除できます）
  • 上の検索枠は名前・@handle・描いた VTuber 名・プロフィール文・🎨絵柄の名前・利用の記載の名前・Skeb検索のタグで絞れます（「Live2D」「立ち絵」「デフォルメ」「商用OK」「ブルアカ」「ウマ娘」等も検索可）。タグは5人以上に付いている語だけが対象で、🔍詳細ビューの 🏷 から押しても検索できます

🚫 除外（合わない絵師を弾く）

カード右上の 🚫除外 を押すと、その絵師はこの端末で今すぐ非表示になります。 上に出る「コレクションに反映」のコマンドを巡回PCで実行すると、今後も収集しません。

上部バーの「一覧を見る」（スマホは⚙内の「🚫 除外一覧」）で除外済みを確認できます。 この端末の除外はカード表示され「↩ 解除」でその場で戻せます。コレクション恒久除外（反映済み）は データ本体が削除済みのため @handle の行リスト表示となり、復帰は「復帰コマンド」を巡回PCで実行します。

⭐ お気に入り（3〜4人で共有）

カード右上の ⭐ を押すと、その絵師がチーム全員の共有お気に入りに入り、 誰が付けたか（表示名）も出ます。初回だけ表示名を訊きます（端末に保存）。 上部バーの「表示名」から変更、絞り込みの ⭐自分 / ⭐全員 で候補だけに絞れます。 同じ絞り込みの下のほうに⭐を付けた人ごとの選択肢（「⭐ 田中（12）」＝田中さんが⭐した絵師 12 名）も出るので、ほかの人のお気に入りだけを見られます（スマホは⚙内）。 上部の⭐の行にも人ごとの内訳（⭐ 田中 12・⭐ 佐藤 5 …）が出て、押すとその人の⭐だけ、もう一度押すと元に戻ります（スマホは横にスクロール）。 ⭐は休止中でも隠れません（候補を見失わないため）。「更新」で最新の共有状態に同期します。

➕ 絵師を追加（未掲載の絵師を申請）

X などで見つけた絵師がこのサイトに無いときは、右上の「➕ 絵師を追加」（スマホは⚙内）に Skeb の URL（skeb.jp/@xxxx）を貼ってください。次回の自動更新（毎日11時ごろ）で 収集・掲載され、申請したあなたの⭐に自動で入ります。登録済みの絵師ならその場でカードを表示します。 ※Skeb に存在しない URL や、イラストを提供していない絵師（ボイス専業等）は掲載されません。

🔍 詳細ビュー・選定ステータス・共有メモ

カードの 🔍 ボタン（イラスト表示ではタイルを押す）で、その絵師の作品を最大6枚・プロフィール文（先頭200字）・ 選定ステータスとチーム共有メモを開けます。ステータス （検討中 → 打診済 → 発注済 → 納品済 / 見送り）とメモは全員に共有され、 二重打診の防止と「なぜ⭐したか」の記録に使います。カードにも状態チップと 📝 が出ます。

🔍詳細ビューの「🤝 Skeb で似ているクリエイター」は、Skeb がその絵師のページに出している公式の一覧です（取得できた絵師だけ・最大6名）。 この一覧に載っている絵師は押すとその詳細へ（この端末で🚫除外中なら 🚫 付き）、まだ載っていない絵師（まだ見つけていない・掲載の条件に合わない等）は Skeb のページを開きます。気に入った1人から芋づる式に探すときに。

📊 比較：🔍詳細ビューの「📊 比較に追加」で最大4名を入れると、件数の横に「📊 比較 N 名」が出ます。押すと価格・納期・完了率・受注数・有名度・VTuber適性・絵柄・利用の記載（お気に入り共有があるときは⭐・状態/メモも）を横に並べて見られます（最終候補の見比べ・社内相談に。この端末に保存・イラスト版とコミック版は別々）。

⚠ 発注前に知るべき Skeb の制度

  • リテイク不可：Skeb は「おまかせ」形式で、納品後の修正指示は原則できません
  • 著作権は絵師に帰属：権利譲渡はなく依頼者の利用範囲は限定的です。事務所公式の立ち絵・商用利用が目的の場合は、Skeb 外での直接契約（権利許諾・料金は別相場）が通例です
  • 表示価格は最低額：カードの金額は絵師が設定した「おまかせ最低額」で、キャラデザ・立ち絵の実際の依頼額はその数倍になるのが普通です
  • 上記は 2026-07 時点の要約です。発注前に必ず Skeb 公式の最新規約・利用範囲をご確認ください

データの鮮度

受付状況・価格は収集した時点の情報です。各カードの「確認 ○日前」がその絵師の最終確認日、上部の「データ更新 M/D」が最新ビルド日です。募集は Skeb 側で急に締まることがあるため、発注前に絵師名をクリックして Skeb の最新をご確認ください。

作品サムネ・発注

カードの作品画像はクリックで拡大表示されます（画像は Skeb の参照表示）。拡大内の 「Skebで作品を開く」から作品ページへ。発注は絵師名（または @handle）をクリックして Skeb の正規フローで。社内専用のため URL・パスワードの共有は控えてください。

@handle 横の 𝕏 は Skeb 連携元の X アカウント（同名ハンドル）を開きます。 X 側で改名・移転している場合はリンク切れになるため、その際は Skeb ページから最新のリンクをご確認ください。
